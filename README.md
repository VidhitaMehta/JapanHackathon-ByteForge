# Photos for Shinzoku Setu

Put photos in this folder using exactly these file names. Until a file exists, the app shows a labelled grey placeholder in its place.

| File name | Where it shows | Suggested subject |
|---|---|---|
| `hero.jpg` | Home page banner (wide, about 1600×600) | Japanese food products on an Indian store shelf |
| `tool-label.jpg` | Label Check card | Back of a Japanese snack package |
| `tool-shelf.jpg` | Shelf-Life card | Shipping containers at a port |
| `tool-price.jpg` | Price Builder card | An Indian store shelf with price tags |
| `tool-map.jpg` | Launch Map card | An Indian city street or market |
| `tool-partner.jpg` | Partner Check card | Two people in a business meeting |
| `tool-plan.jpg` | Roadmap card | Planning documents on a desk |

**Use only photos you are allowed to use:** your own photos, or free-licence photos from sites such as Unsplash or Pexels (check each photo's licence). Don't copy photos from JETRO or other company websites.

Tips: landscape JPGs, under about 500 KB each, so the app loads fast.
